# Kids Learning App – Android Development Project

I’m proud to present a mobile application that my team and I built as our final project in mobile development. The goal was to create something fun, interactive, completely free, and easy for children to use.

## Features
- Text-to-Speech for instructions and phrases
- Alphabet activity with letter tracing and guided phrases
- Counting activity with number tracing and guided phrases
- Math activity with randomized questions and answer validation
- Unique profile system using colors and shapes
- Progress saving so users can continue where they left off
- Works without requiring an internet connection

## Technologies Used
- Java
- Android Development
- SQLite (for storing profiles, progress, and traced data)
- GitHub (for version control and team collaboration)

## My Role
I focused on developing the alphabet and counting activities. This included implementing text-to-speech features and storing traced letters and numbers as data using SQLite.
